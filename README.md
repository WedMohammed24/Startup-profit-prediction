Startup Profit Prediction

📌 Project Overview

This project focuses on analyzing startup companies’ data and building a Machine Learning model to predict their Profit based on different types of business expenditures.

The project uses a dataset containing information about 50 startup companies and applies Linear Regression to predict startup profits.

🎯 Project Objective

The main objective of this project is to:

* Explore and understand the startup dataset.
* Analyze the relationships between different expenditures and Profit.
* Visualize the data using different plots.
* Build a Linear Regression model.
* Predict Profit using the selected features.
* Evaluate the performance of the model on training and testing data.

📊 Dataset

The dataset contains information about 50 startups.

The main features used in the model are:

* R&D Spend — Spending on Research and Development.
* Administration — Administrative spending.
* Marketing Spend — Marketing-related spending.

Target Variable

* Profit — The profit generated by the startup.

🔍 Data Analysis

Before building the model, the dataset was explored and checked for:

* Missing values
* Duplicate values
* Dataset structure and information
* Descriptive statistics

Several visualizations were also created to better understand the distribution of Profit and the relationships between the variables.

🤖 Machine Learning Model

A Linear Regression model was used to predict Profit.

The dataset was divided into:

* 70% Training Data
* 30% Testing Data

The model was trained using the following features:

R&D Spend
Administration
Marketing Spend

The target variable was:

Profit

📈 Model Evaluation

The model was evaluated using:

* R² Score
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)

The project also compares the model’s performance on both Training Data and Testing Data.
